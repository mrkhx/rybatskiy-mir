# 3D Art Bible — Рыбацкий Мир

Стиль: **stylized semi-realistic**. Не photoreal, не low-poly cartoon, не Roblox, не flat-shaded prototype как «финал».

Референс настроения: спокойное лесное озеро, мягкий дневной свет, благородная зелёно-сине-бирюзовая палитра. Кадр должен быть уютным и «дорогим», как современная mid-core 3D-рыбалка.

## 1. Принципы

- Читаемый силуэт важнее микротекстур.
- Материалы: немного roughness-variation, без грязного PBR-шума.
- Цвет: приглушённый, без кислотной насыщенности.
- Масштаб человека = 1.0. Мостик, камыш, удочка живут в реальном метре.
- Один художественный язык на персонажа, рыбу, деревья, UI.

## 3. Персонаж

- Взрослый мужчина, естественные пропорции (не hero-1.8-shoulders).
- Рост ~178 см.
- Куртка/худи, штаны, резиновые сапоги, кепка.
- Лицо не photoreal skin shader v1 — стилизованный, без пор.
- Rig: humanoid (Unity Humanoid), root motion выкл. для slice.
- Оружие/удочка — **отдельный скелетный/procedural объект**, не впечён в меш рук.

Полибюджет персонажа slice: 15–25k tris, 2–4k maps (albedo, mask, normal).

## 4. Локация slice

Радиус игровой зоны ~60–80 м. Чаша озера, один мостик, тропинка, камыш, 2–3 коряги, кувшинки у кромки.

Не open world. Не бесконечный лес с гизмо-деревьями до горизонта без LOD.

## 5. Растительность

- Сосны и смешанный лес, не пальмы и не generic Unity tree pack «как есть».
- Камыш — карты/меш с vertex wind, разные фазы.
- Кувшинки — отдельные меши, не декаль на воде.
- LOD0 / LOD1 / billboard. На LOW — сразу LOD1+billboard.

## 6. Вода

Озёрная, не океан.

- Гестнер/синус, маленькая амплитуда.
- Цвет по глубине (shore fade).
- Мягкие отражения: planar или SSR только HIGH.
- Пересечение с сваями: foam/dark wet.
- Круги: декаль/ripple RT, не fullscreen overlay.

## 7. Рыба

Одна stylized mesh (окунь) для slice. Под водой — tint + caustic, не аквариумный шейдер. В fight видна как объём, не UI-иконка.

## 8. Текстуры и naming

```
T_<Asset>_<LOD>_<Map>.png
SM_<Asset>_<LOD>.fbx
SK_<Character>.fbx
A_<Anim>.fbx
M_<Asset>.mat
VFX_<Name>.prefab
SFX_<Name>.wav
```

Карты: 2K для hero/pier/water, 1K для props, 512 для far trees.  
Никаких 8K «на всякий».

## 9. Освещение

- Один directional (солнце) + sky ambient.
- День: тёплый key, холодный fill с воды.
- Вечер: низкое солнце, amber.
- Ночь: луна холодная, костёр не в slice.
- Без десятка point light на мостике.

## 10. UI в 3D

- Explore: почти пустой HUD (стики на мобилке, точка взаимодействия).
- Fishing: compact overlay снизу, не 40% экрана.
- Шрифты: humanist sans для UI, serif только для названия водоёма.
- Язык: русский.
