# Архитектура — фундамент

Монорепозиторий, модульный монолит. Микросервисы на этом этапе не используются.

## Приложения

| Приложение | Роль |
|---|---|
| `backend` | Авторитетный источник игровых данных. NestJS. |
| `frontend` | Клиент VK Mini App / браузера. React + Vite. |
| `admin` | Служебная панель. React + Vite. |

Инфраструктура: PostgreSQL (Prisma), Redis, Socket.IO, Docker Compose.

## Модули backend (сейчас)

- `health` — живость процесса, PostgreSQL, Redis
- `auth` — сессия игрока, контракт VK-провайдера
- `player` — профиль игрока на основе `User`
- `realtime` — инфраструктурный Socket.IO handshake (не чат)

Игровые домены (рыбалка, турниры, клубы, магазины, экономика, крафт, Premium, чат и т.д.) **намеренно отсутствуют**. Их нужно добавлять отдельными модулями, когда появится конкретная задача.

## Данные

На этапе фундамента одна таблица `User`. Схема будет расширяться миграциями Prisma, без переписывания каркаса.

## Realtime

Socket.IO подключён как транспорт. Игровые события, чат и синхронизация мира появятся позже. Клиенты не должны считать клиентское состояние источником истины.

## Будущее расширение

Каркас не фиксирует конкретные игровые сущности, но оставляет место для:

- водоёмов, видов рыб, трофеев;
- рейтингов и турниров;
- клубов, чата, Premium;
- магазинов, аукциона, транспорта;
- навыков, перков, NPC, экспедиций;
- погоды, сезонов, мировых событий.

Новые домены = новые NestJS-модули + миграции, без выделения сервисов.
